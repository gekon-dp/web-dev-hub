### 🗂 Web Dev Vault (Моя база кода)

Добро пожаловать в мой личный репозиторий-архив! Здесь я собираю полезные блоки кода, переиспользуемые UI-компоненты, алгоритмы и шаблоны для веб-разработки. Репозиторий разбит по технологиям и постоянно дополняется по мере моего обучения и роста. 

### 🛠 Технологический стек

- **Frontend:** HTML5, CSS3, JavaScript (ES6+), TypeScript, React
- **Backend:** Node.js

### 📂 Структура репозитория

### 🌐 1. HTML (/html)

- /templates — готовые шаблоны чистой разметки, заготовки под Landing Page, SEO-скелеты и Email-письма.

### 🎨 2. CSS (/css)

Компоненты и элементы интерфейса, построенные исключительно на чистом HTML5 и CSS3 (без использования JavaScript). Каждая подпапка содержит index.html и style.css:

- footers — различные варианты подвалов сайтов (footer).
- accordions — легкие аккордеоны (реализованные через тег <details> или CSS-интерсепторы).
- cards — карточки товаров, профилей и блогов с адаптивной сеткой Flexbox/Grid.

### 🟨 3. JavaScript (/js)

- /components — интерактивные UI-элементы. Каждая папка автономна и содержит три файла (index.html, style.css, script.js): 
  - accordions — готовые аккордеоны.
  - dropdowns — выпадающие списки и меню.

- /utils — библиотека чистых JS-функций (хелперов) для работы с данными: 
  - arrays — утилиты для массивов (сортировка, фильтрация, подсчеты).
  - objects — утилиты для объектов (копирование, трансформация).
  - strings — функции для работы со строками (форматирование, обрезка текста, slugify).
  - validators — проверки валидности данных (проверка email, корректность телефона, проверка на пустоту).

### ⚛️ 4. React (/react)

- /components — переиспользуемые JSX/TSX компоненты (модальные окна, карточки, табы).
- /hooks — кастомные React-хуки (useFetch, useLocalStorage и др.).

### 🔷 5. TypeScript (/typescript)

- /interfaces — примеры правильной типизации сложных объектов и API-ответов.
- /generics — универсальные переиспользуемые функции с поддержкой дженериков.

### 🟢 6. Node.js (/node)

- /api — шаблоны для построения REST API и CRUD-запросов.
- /auth — готовые модули авторизации и регистрации (JWT-токены, сессии).

### 🚀 Как этим пользоваться

1. Найдите нужную технологию и компонент в дереве папок.
2. Скопируйте готовый кусок кода или скачайте папку с компонентом.
3. Прочитайте локальный файл README.md внутри папки компонента, если для его работы требуются дополнительные настройки или NPM-пакеты.

### 📝 Шпаргалка по добавлению кода (Git)

Когда я добавляю новый сниппет, я использую эти команды: 

bash

git add .
git commit -m "feat: добавил функцию/компонент <название>"
git push origin main

Используйте код с осторожностью.
